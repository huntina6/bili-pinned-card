v1.6.0Node ≥ 18Windows · macOS · Linux

功能特性

一个命令行程序，覆盖置顶评论的全生命周期

🛰

实时监测

分钟级轮询，自动识别置顶评论换新 / 置顶动态替换 / 取消置顶，变化即出图。

🎴

置顶评论卡片

深色渐变 + 粉色徽标设计，头像、正文、表情内联、图片网格，2x 高清输出。

💬

UP 互动回顾

取消置顶/换新时，拉取全部子回复，筛选 UP 回复与 UP 点赞，自动生成对话链回顾图。

🔥

UP 热评 TOP 卡

指定动态或自动检索账号全部动态，每条 UP 一级评论出一张卡：UP 回复上下文全量回顾 + 粉丝高赞 TOP N，文件名即评论发布时间。

🖼

图片按比例展开

解析图片真实尺寸，横图、竖图、长图完整显示，绝不裁剪变形。

📦

纯 Node 实现

无需浏览器（零浏览器依赖），匿名可用亦可扫码登录；@resvg/resvg-js 跨平台预编译，安装即用。

⚙️

可挂 cron

命令行模式支持 --uid/--oid/--cookie/--watch，配置持久化，安静模式适配脚本。

🎨

自定义分辨率

1x/2x/3x 或任意宽度（340–4080px）自由选择；Unicode emoji 转 Twemoji 彩色内联图，图床缩略图加速（头像 65KB→约 2KB），超长卡片自动高度预算。

🔍

内容规则

--rule 关键字或 /正则/flags 过滤，多条支持任一 / 全部命中；只有命中的置顶评论才出图，默认关闭、行为与旧版一致。

🔔

事件推送

--notify-webhook 在置顶变化 / 取消置顶 / 动态更新 / 热评完成 / 凭据失效时推送，内置通用 JSON、飞书、钉钉、Telegram 模板，失败不影响监测；交互向导内亦可多项勾选订阅事件（--notify-events，全不选即不推送任何事件）并设置标题前缀。

🛡

风控友好

请求节流 + 风控自适应退避、浏览器风格请求头、bili_ticket 风控票据；扫码 / 游客 / 手动 Cookie 三种登录方式。

🧭

交互向导

步骤化向导：登录/模式/目标/监测/推送/输出逐项配置，每步可「返回上一步」，链接解析失败可就地重填；确认页支持「仅保存不运行」「返回修改」「清空已保存配置」；单次任务完成后可返回菜单再运行。

快速开始

三分钟跑起来

安装
# 需要 Node.js ≥ 18
git clone https://github.com/huntina6/bili-pinned-card.git && cd bili-pinned-card
npm install
扫码登录（推荐首次使用，替代手动粘贴 Cookie）
node cli.js 登录
看这条动态的置顶评论并出图（直接粘链接）
node cli.js 查看 https://www.bilibili.com/opus/1232243387332034584
绘制指定评论（旧的置顶评论也行）
node cli.js 出图 "https://t.bilibili.com/407750907?comment_root_id=319181633760"
生成 UP 互动回顾图（自动识别 UP）
node cli.js 回顾 "https://t.bilibili.com/407750907?comment_root_id=319181633760"
UP 热评 TOP 卡（单动态，每条 UP 评论一张，高赞区 10 条）
node cli.js 热评 https://www.bilibili.com/opus/1232243387332034584 10
UP 热评 TOP 卡（全账号自动检索，先询问确认）
node cli.js 热评 --UP 401315430 --cookie "SESSDATA=xxx" --确认
持续监控 UP 主（粘空间链接，每 60 秒检查）
node cli.js 监控 https://space.bilibili.com/401315430 60 --cookie "SESSDATA=xxx; bili_jct=yyy"
自定义分辨率（默认 2x，可 1x/3x 或任意宽度）
node cli.js 查看 https://www.bilibili.com/opus/1232243387332034584 --宽度 2040
内容规则：只对命中「抽奖」或 /预告|置顶/i 的置顶评论出图
node cli.js 监控 https://www.bilibili.com/opus/1232243387332034584 --规则 "抽奖" --规则 "/预告|置顶/i"
事件推送到飞书机器人（默认关闭）
node cli.js 监控 https://space.bilibili.com/401315430 --cookie "SESSDATA=xxx" --推送 "<飞书机器人URL>" --推送格式 feishu --推送事件 new,unpinned
给 AI / 脚本调用（stdout 只出 NDJSON，日志走 stderr）
node cli.js 能力  # 能力清单 JSON（自描述）
node cli.js --json 查看 "<动态链接>"
node cli.js --json --演练 热评 "<链接>" 10  # 只报告计划，不出图
主要参数（完整说明书见 node cli.js --帮助：每条命令具体做什么 / 全部功能 / 环境变量 / 退出码；中文名、英文名、旧参数名三种写法等价）
参数说明
登录扫码登录：终端二维码，手机 B站 App 扫码后自动保存 Cookie（--login）
查看 / 监控 / 热评 / 出图 / 回顾 / 帮助动作词（一句话命令）：看一次 / 一直盯 / UP 热评卡 / 指定评论出图 / UP 互动回顾 / 帮助；除「监控」外都是跑一次就退出
--动态 <链接|ID>动态链接或 ID（含其置顶评论；支持 Opus / t.bilibili.com 短链自动转换）（--dynamic / --oid）
--UP <UID|空间链接>目标 UP 主，可写 UID 或 space.bilibili.com/xxx 空间链接（--up / --uid）
--评论 <链接|ID>评论链接或 ID，直接绘制该评论卡片（评论分享链接会自动带出所属动态）（--comment / --rpid）
--类型评论对象类型（默认 11=动态；1=视频 12=文章 14=音频），一般无需手动指定
--回顾与 --评论 联用，生成 UP 互动回顾图（--context）
--热评 [N]UP 热评 TOP 卡（默认 N=10）；省略 N 时沿用上次保存的 TOP 值；配合 --UP 自动检索账号全部动态
--动态上限 / --确认限制处理动态条数 / 非交互跳过确认询问（--max-dyns / --yes）
--cookie登录 Cookie（可选）：完整子回复 + 降低风控
--监控 / --单次持续监控 / 单次检查（--watch / --once）
--追踪动态同时监测普通动态更新（--track-dyn）
--规则 / --规则模式内容规则（关键字或 /正则/flags，可重复）；any=任一命中（默认）/ all=全部命中。仅命中规则的置顶评论才出图（--rule / --rule-mode）
--推送 / --推送格式事件推送（默认关闭）；消息体模板 generic / feishu / dingtalk / telegram（--notify-webhook / --notify-format）
--推送事件 / --推送群 / --推送前缀订阅事件（new,unpinned,dyn-update,up-top,error）：不传=全部订阅，显式传空串=不订阅任何事件 / Telegram chat_id / 标题前缀（--notify-events / --notify-chat-id / --notify-prefix）
--倍率 / --宽度渲染倍率（默认 2，0.5~6）/ 自定义输出宽度像素（340~4080，优先）（--scale / --width）
--强制强制重新出图（忽略已出图状态）（--force）
--无表情关闭 Unicode emoji 彩色化（默认 Twemoji 内联图）（--no-emoji）
--回复 / --间隔 / --输出卡片绘制精彩回复 / 监控间隔（默认 60s）/ 输出目录（默认项目目录 output）（-r / -i / -o）
--静音 / --版本 / --免向导安静模式 / 版本号 / 非交互直接运行（-q / -V / --no-input）
--向导 / -I即使已提供目标也强制进入交互向导（默认仅在缺少参数时进入）（--interactive）
